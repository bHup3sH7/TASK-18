Greeting Page
A simple interactive web page built with HTML, CSS, and JavaScript.

# What This Project Does

Shows a "Hello" message at the top of the page
Has four coloured boxes — Red, Blue, Green, and Yellow
Lets you type your name and click a button to get a personalised greeting
Clicking a box changes its background to that colour

Files
greeting_page.html → The only file you need. Open it in any browser.

## How to Run

Download greeting_page.html
Double-click it to open in your browser
No installation needed

### Example

If you type "Alice" and click Greet, the header changes to:
Hello, Alice!
If you click the Red box, its background turns red.
